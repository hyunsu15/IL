# 2024-05에 작성한 ZGC 관련 내용

## 꼬리 지연이 줄었다.

cg 멈춤은 꼬리지연에 유효하다. 특히 신뢰성있는 기능에서 효과가 있는데, 해당 기능으로 지연을 줄였다

## 효율적이다.
알려진 내용에 따르면, ZGC를 도입하면 처리량이 줄어든다고 알려져있다. 하지만 G1을 썻을때와 비슷하거나 같았으며, 오히려 더나은 Cpu 사용률을 보였다.

## 운영적인 간단화

비세대적ZGC는 G1대비해서 cpu 사용을 36% 더했다.하지만 세대적ZGC 는 G1보다 10% 더 썼다.
튜닝없이 ZGC 기본값으로도 동작함.


## 메모리 오버헤드

ZGC는 G1보다 3% heapsize 고정으로 오버헤드가 가지고있다. 그래서 G1보단 메모리를 더 요구한다.하지만 평균보다 높은 네이티브 메모리 사용량을 필요로 하는 일부 서비스를 제외하면, 더 많은 여유 공간을 확보하기 위해 최대 힙 크기(Max Heap Size)를 줄여야 했던 경우는 거의 없었습니다.
(이후 다음 단락은 이해못함.)



## 세팅

최소힙/최대힙 동일하게 세팅

-XX:+UseTransparentHugePages 
메모리 페이지 단위를 좀 크게 받는것. 이것은 os설정도 건드려야함.


-XX:+AlwaysPreTouch
힙 메모리 전체를 미리 한 번씩 건드려서(touch) 실제 물리 메모리를 확보해 두는 옵션
대신 기동시간이 느려짐.
