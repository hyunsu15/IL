## 읽을 때 주의할 점

읽으면서 걸렸던 것들. 무비판적으로 받아들이면 안 될 것 같아서 적어둔다.

### 1. 생존 편향이 심하다

아마존이 성공했으니 이 서한들이 지혜로 읽힌다. **같은 원칙을 쓰고 망한 회사들의 서한은 아무도 읽지 않는다.**

"장기를 보고 단기 이익을 포기하라"를 실행하다가 현금만 태우고 죽은 회사가 훨씬 많다.
서한이 옳아서 성공한 건지, 성공했기 때문에 옳아 보이는 건지는 구분이 안 된다.

### 2. 이건 회고가 아니라 IR 문서다

주주서한은 근본적으로 **설득 목적의 글**이다.
아마존은 20년 가까이 이익이 거의 없었고, 왜 계속 투자해야 하는지를 주주에게 납득시켜야 했다.

결과적으로 맞았지만, 쓸 당시엔 변론이었다.
그래서 실패가 거의 안 나온다. 노동 환경 논란, 셀러와의 관계 같은 건 없다.
**자기가 고른 프레임 안에서의 자기 서술**이다.

> 참고로 버핏 주주서한은 이 점에서 정반대다. 실패한 인수를 이름과 금액까지 붙여서 반복해서 쓴다.

### 3. 규모가 전제로 깔려 있다

- "크게 베팅하고 많이 실패하라" → 실패를 흡수할 현금이 있어야 가능
- "장기를 보라" → 그걸 참아줄 자본시장 신뢰가 있어야 가능. 보통 회사는 두 분기 적자면 대표가 바뀐다
- 6-pager → 글 잘 쓰는 사람들과 읽을 시간이 있는 조직에서만 굴러간다

### 4. 원칙이 아니라 사례로 읽자

"이 회사는 이 상황에서 이렇게 판단했다"까지가 정보고,
"그러니 나도 그래야 한다"는 비약이다.
